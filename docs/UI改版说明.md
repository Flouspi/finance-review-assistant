# 智合规审查工作台

本次依据用户的两张 UI 参考图改造现有 Python / Streamlit 应用，继续由 LangGraph 执行原有五类审查与自有知识库检索。

## 设计

- 左侧深蓝导航：品牌、新建审查、当前会话记录、已审数量。
- 对话审查：用户问题、回答摘要、优先风险卡片、其余条目、完整回答。
- 报告总览：条款摘录、综合风险等级、风险分布、关键发现与建议。
- 原文与依据：查看实际审查原文、知识片段和执行路径。
- 保留参考图的侧栏、对话、风险卡片和报告左右分栏。页面以灰白、深蓝为主，主操作使用低饱和蓝灰；高/中/低风险使用红/褐/灰，去掉绿色。
- 删去宣传式标题、装饰英文、菱形图标和重复的完成提示。保留材料要求、风险依据和人工复核等实际说明。

## 数据与功能

风险数据来自本次模型返回的结构化条目，不复制参考图的 86 分、3/5/9 数量、37 页、28 份审查或其他示例统计。没有评分算法，因此显示风险等级而非分数。

第二次审查模型调用同时请求完整回答与风险条目，未增加第三次调用。每条可包含风险等级、条款号、原文、原因、建议、建议替换文本和证据编号。解析失败时回退到完整回答并明确不统计风险数量。

原文定位采用去除空白后的精确文本匹配；没有匹配到会标记待核对，不虚构 PDF 页码或高亮位置。证据编号限定在本次检索结果范围内，不存在的编号不会展示为有效依据。

“修改建议清单”下载模型建议的 Markdown，不自动改写上传的原合同。“标记人工复核”仅更新当前会话记录的状态，不发送给外部人员或执行审批流。

追问会携带当前记录的原始材料与最近审查意见，输入超过长度限制时明确报错。新建记录与上传新材料独立，切换历史不会跨用户共享内容。记录不具备跨会话永久保存能力。
