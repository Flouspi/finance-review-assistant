# 界面修复与云端更新

截图显示应用已启动。页面文字难读是浅色 CSS 与深色主题混用导致，本次已修复并验证两种主题。

页面仍显示“连接 Dify”说明实际运行的 app.py 仍是旧版，或云端尚未载入最新提交。右侧安装日志未显示 Python 启动异常。

1. 在 GitHub 仓库根目录选择 Add file → Upload files。
2. 将“GitHub上传文件”文件夹里面的全部内容上传，保持 app.py、judge_app.py、requirements.txt 位于根目录。不要只更新 knowledge 文件夹，因为旧代码不认识 JSONL 知识记录。
3. 确认 knowledge/智合规_v1.0.jsonl 和 sources/原工作簿也在仓库中，提交更新。
4. 在 Streamlit 的应用管理菜单选择 Reboot app；重启后刷新页面。可关闭右侧日志面板，以恢复页面完整宽度。
5. 在 Settings → Secrets 中确认 MODEL_API_KEY 已填写真实值，KNOWLEDGE_BACKEND = "local"。模型密钥不发到聊天，也不上传 GitHub。

正常新版不再显示“连接 Dify”。如果仍缺配置，红色提示会明确指出“模型连接”或“法规知识库”未就绪。当前本地知识库已接入；云端需随应用上传它。

本次26项测试通过，浅色/深色实际浏览器检查通过。公开网址上的修复仍须更新后确认。
