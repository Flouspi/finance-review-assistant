# 面向评委的云部署

目标仓库：`Flouspi/finance-review-assistant`；公网评委入口：`judge_app.py`；建议 Python：`3.13`（本机验证版本为 3.13.16）。

## 当前状态

源码支持云端 Secrets 和评委模式，知识检索直接使用项目 knowledge 文件夹内的自有资料，无需 Dify。已导入 XLSX 的 1,889 条记录；公网服务尚未创建，真实模型密钥仍需配置，资料覆盖与法律适用性仍需验收。

## 一、仓库

将云部署包解压后的内容放在仓库根目录，保证能看到 `judge_app.py`、`app.py`、`requirements.txt`、`finance_assistant/`、原始 YAML 文件和 `.streamlit/config.toml`。不要只上传 ZIP 文件。云部署包中的配置已经移除本机地址绑定。

使用私有仓库时，Streamlit 必须获得访问私有仓库的 OAuth 权限；这与 Codex/GitHub 连接的权限互相独立。仓库可见性与部署后应用的访问权限也互相独立。

将审核选定的法规、制度或业务规则原文放入仓库 `knowledge/`，再运行 `python cli.py --knowledge-check` 验证文件能否解析。云主机不会访问你电脑的 C 盘，资料必须随应用一起部署。本地 `.gitignore` 默认不跟踪资料；使用 Git 命令提交已确定可部署的文件时，需要逐个用 `git add -f knowledge/文件名`，或在 GitHub 网页直接上传文件。上传的待审查合同不应放入 knowledge。

本次的运行时知识库文件为 `knowledge/智合规_v1.0.jsonl`，必须上传到仓库。`sources/智合规_金融合规知识库_v1.0.xlsx` 用于溯源和重新导入，程序不会把这个工作簿里的提示词页当作系统指令。网页“上传待审查材料”不用于导入知识库 XLSX。

## 二、创建云端应用

1. 打开 https://share.streamlit.io/ 并用 GitHub 账号完成登录/注册。
2. 选择 Create app，选择已有应用/已有 GitHub 源码。
3. Repository：`Flouspi/finance-review-assistant`。
4. Branch：选择仓库的实际默认分支，通常为 `main`。
5. Main file path：`judge_app.py`。这是固定启用评委模式的公网入口；`app.py` 仍供本地开发使用。
6. Advanced settings 中选择 Python 3.13；将 `deploy/secrets.example.toml` 的内容复制到 Secrets，填入真实值。
7. 点击 Deploy，等待依赖安装和页面启动。

## 三、云端凭据

Secrets 顶层配置示例（下面是占位值，不是可用凭据）：

```toml
EVALUATION_MODE = true
MODEL_API_KEY = "替换为模型密钥"
MODEL_BASE_URL = "https://api.deepseek.com"
MODEL_NAME = "deepseek-flash"
KNOWLEDGE_BACKEND = "local"
```

评委模式固定使用修正版和项目自有知识库，隐藏 API 地址、密钥、模型与版本选择。评委无需填写任何密钥。缺少模型密钥或知识库为空时，页面提示服务尚未配置并禁用提交。旧 Secrets 中的 Dify 配置不会启用远程知识检索，可将其移除。

真实模型凭据只在云平台的 Secrets 中填写，不放入仓库，也不提交 `.env` 或 `.streamlit/secrets.toml`。知识检索采用 BM25 文本匹配，不调用 Dify，不依赖额外的向量化服务。生成审查回答仍会调用配置的模型 API，并将需要分析的材料与检索片段发送给该模型服务。

## 四、交给评委前验收

1. 从应用分享设置中确保评委可访问；若设为 Public，任何拿到链接的人均可能访问。若使用平台私有分享，需要事先确认评委能完成平台要求的访问流程。
2. 用未登录 GitHub/Streamlit 的浏览器窗口打开真正的应用 URL，通常为 `https://实际子域名.streamlit.app`。
3. 分别测试 `examples/cases.json` 中五类问题，确认分类、检索结果和模型回答。
4. 上传一份可提取文字的 DOCX 或 PDF，确认正文参与审查。
5. 下载一份报告，核对实际法规来源与模型引用。
6. 用手机移动网络或其他独立网络打开同一地址。确认访问正常后，再将链接和简单操作说明发给评委。

云平台可能存在休眠、资源限制、网络与服务商 API 可达性问题，实际可用性以部署后测试为准。模型 API 的费用由配置密钥的账号承担。
